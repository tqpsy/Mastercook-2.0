# Mastercook 2.0

Assistente domestico per organizzare i pasti della famiglia: menu settimanale, ricette, inventario di frigorifero, freezer e dispensa, scadenze, lista della spesa e riduzione degli sprechi.

Stato: **Fase 0, progettazione**. Non c'è ancora codice applicativo.

I documenti di progetto sono in [`docs/fase-0/`](docs/fase-0/); si parte da [`00-sintesi-e-decisioni.md`](docs/fase-0/00-sintesi-e-decisioni.md).

Il progetto precedente, [tqpsy/Mastercook](https://github.com/tqpsy/Mastercook), è stato consultato in sola lettura e non viene modificato.
